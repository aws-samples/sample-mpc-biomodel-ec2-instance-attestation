System Overview

This system enables secure protein structure prediction using the Boltz-1 model with hardware-level security guarantees through AWS NitroTPM attestation. Two roles collaborate while maintaining cryptographic separation of concerns.

🧬 Biologist Workflow

The biologist's primary goal is to predict 3D protein structures from amino acid sequences. All sequences are encrypted before leaving the browser, and can only be decrypted by attested backend instances.

Prerequisite: attestation before sealing. before encrypting anything, the biologist connects to the backend, verifies its attestation (Connect & Verify → check PCRs against the browser trust store), and binds the alias/boltz-sequence-key KMS policy to those PCRs. Only then is a sequence sealed, so that it can be decrypted only on a backend whose measurements were already trusted. The flow below shows the sealing and prediction steps that follow.

🔬 Biophysicist Workflow

The biophysicist manages model weights, downloads updates from HuggingFace, and coordinates secure deployment to backend instances.

Prerequisite: attestation before sealing. as with the biologist, the biophysicist verifies backend attestation and binds the alias/boltz-model-key KMS policy to the attested PCRs before producing encrypted weights. The update flow below produces the envelope-encrypted weights in S3; deploy then reloads them in-place, where the backend decrypts them only under attestation (KMS Recipient flow) and re-extends PCR16 with the new model hash.

🔄 In-Place Update

Hot-swap model weights without instance restart.

  • Zero downtime
  • Same PCR4/PCR7 values
  • PCR16 changes (model hash)
  • Faster deployment
♻️ Instance Recycle

Rolling replacement via ASG refresh.

  • Clean instance state
  • New AMI if available
  • All PCRs may change
  • 50% minimum healthy
